Politique de Confidentialité - HalalCheck

Dernière mise à jour: Avril 2026

1. Introduction

HalalCheck est une application mobile gratuite permettant de vérifier le statut halal des produits alimentaires. Nous prenons votre vie privée très au sérieux.

2. Données collectées

HalalCheck ne collecte aucune donnée personnelle. L'application fonctionne entièrement en local sur votre appareil.

Les seules données stockées sont:

  • Votre préférence de langue (stockée localement sur votre appareil)
  • L'historique des produits scannés (stocké localement sur votre appareil)
  • Les additifs récemment recherchés (stockés localement sur votre appareil)

Ces données ne quittent jamais votre appareil et ne sont jamais envoyées à nos serveurs.

3. Données tierces

Lorsque vous scannez un code-barre, l'application interroge la base de données publique OpenFoodFacts (world.openfoodfacts.org) pour obtenir les informations du produit. Cette requête contient uniquement le code-barre du produit, sans aucune information personnelle.

4. Permissions utilisées

L'application utilise uniquement la permission Caméra pour scanner les codes-barres. Cette permission n'est utilisée qu'à cette fin.

5. Publicités

HalalCheck ne contient aucune publicité et ne partage aucune donnée avec des annonceurs.

6. Sécurité

Toutes les communications réseau utilisent le protocole HTTPS sécurisé. Aucune donnée sensible n'est transmise.

7. Enfants

HalalCheck ne collecte pas de données sur les enfants de moins de 13 ans, ni sur aucun autre utilisateur.

8. Modifications

Nous nous réservons le droit de modifier cette politique de confidentialité. Les modifications seront publiées sur cette page.

9. Contact

Pour toute question concernant cette politique de confidentialité, contactez-nous via la page du Play Store.
